# project-os-start

Read AGENTS.md, START.md and .project-os.json from the workspace root. Follow the bootstrap procedure.
Inspect the board, decisions, pending questions and repository manifests. Do not read secret values or implement product code during onboarding.
Report actual native agent/tool availability and effective model settings; a template file does not prove a tool ran.
Reuse known user decisions. Record only genuine scope and permission references. Propose the first task and stop at any missing authority.
The main session is the PM. Use project_os_pm only for a bounded delegated planning brief, not a recursive PM loop.
