## Launch announcement

Project OS now supports Claude Code and Codex from the same repository. Pick either client or both during setup. Tasks, decisions and QA records stay in one planning directory, so you can switch clients between steps without rebuilding project context. The Codex adapter includes agent role definitions and reusable skills.

## Portfolio overview

I created a project management structure for Claude Code and Codex with separate planning, development and QA responsibilities. A shared workflow sits behind client-specific entry files, skills and role definitions. The repository includes a local example, setup scripts and automated checks for each runtime selection.
