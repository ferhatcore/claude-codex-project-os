## Launch announcement

Claude Code Project OS is a set of files for organising work in Claude Code. A PM session keeps track of tasks and decisions, developer sessions make changes, and QA checks the result. It includes templates, a local example and setup scripts. Progress stays in files so a new session can pick up where the previous one stopped.

## Portfolio overview

I created a project management structure for Claude Code with separate responsibilities for planning, development and QA. The repository includes the working files, installation scripts, a local example and automated checks. It supports one repository or several related repositories, with explicit approval for Git operations and deployment.
