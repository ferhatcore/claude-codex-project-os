# v1.0.0 release notes — draft

Claude Code Project OS coordinates AI-assisted project work through local files, named roles, explicit approvals and independent QA.

Included: PM and worker rules, code/design/document/review pipelines, task and evidence templates, recovery instructions, configurable model tiers and budget profiles, multi-repository onboarding, an offline installer, checks, a fictional reading-list CLI example and a reproducible real-session smoke-test procedure.

Node.js 22+ is required for helper scripts. Claude Code and an authenticated account are required for AI sessions. There is no npm dependency, daemon, automatic session controller, cost-enforcement service or scheduler.

Known limits: prompts do not enforce permissions; actual usage/model availability must be checked in the account; native session integrations vary by client; an authenticated end-to-end AI run and hosted CI have not been completed for this candidate. See [readiness](READINESS.md).

Local finalization on 2026-11-11: eighteen system tests, eleven smoke-helper tests and three standalone example tests passed. Authenticated access was unavailable (`loggedIn: false`); the new helper's offline reports do not claim otherwise. No runtime dependency was added.
