# Notes for v1.0.0

Project OS supports Claude Code, Codex or both from one repository. The installer selects the entry files and Codex role/skill definitions while keeping one set of task, decision and QA files.

The update includes four Codex role definitions, four workflow skills, runtime-aware workspace validation and a shared fictional example. Existing install commands still select Claude Code by default. No package dependencies or global client settings are added.

Use Node.js 22 or newer for the helpers and an authenticated account for your selected coding client. MIT License, Copyright (c) 2026 Ferhat Kosger.
