# Trailboard Catalog

A local demonstration CLI. From this directory, `node catalog.mjs` prints the three seeded fictional titles. `node --test catalog.test.mjs` runs its baseline tests. No npm install is needed. `data.json` is a fixture, not user data.

All arguments are currently rejected with usage and exit status 2. The proposed status-filter task is not implemented. There are no accounts, persistent writes, external APIs or deployments.
